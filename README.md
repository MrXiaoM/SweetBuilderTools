# SweetBuilderTools

Minecraft 无限建筑方块插件

## 简介

这个插件允许你给予玩家一个建筑工具物品，使用这个建筑工具，可以做到
+ 右键放置方块，设置玩家破坏方块后不掉落物品（仅在 1.16.4+ 支持）
  - 活塞推动时，保留方块标签，以防方块被破坏
  - TNT/爬行者爆炸可破坏方块，但不会掉落物品
  - 挖掘后/其它实体更改方块/燃烧殆尽/凋落/结构顶掉等情况移除方块标签
  - 仅支持 1.16.4+ 是因为在这个版本中，服务端加入了将持久数据存进区块里的功能
+ 指定可用方块数量（有限或无限）
+ 允许玩家从你指定的多种方块中切换选择，在生存模式物品栏右键点击物品打开切换菜单

总的来说，这是一个重新实现并改进的*魔法方块*功能，可以方便生存服的玩家进行建筑。

> 本插件理论上可以在 1.8+ 运行，但在 Paper 1.16.4+ 的效果最佳，使用 Spigot 或者在 1.16.4 以下会丢失一些特性。
